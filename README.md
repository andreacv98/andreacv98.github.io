# Andrea Colli-Vignarelli — Personal Portfolio (`andreacv98.github.io`)

Bilingual (EN / IT) personal portfolio website built with **Astro** and deployed to **GitHub Pages**.

- **Live Website**: [https://andreacv98.github.io/](https://andreacv98.github.io/)
- **Content Source**: [`src/data/portfolio.ts`](./src/data/portfolio.ts)

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
